Termos de Uso

Em vigor desde: 2026-10-12

Estes termos estabelecem as condições de uso do OmniSort (o app para Windows, o app para Android e o site), oferecido pela Projectteamforyou (“nós”).

1. Finalidade e concordância

Ao instalar ou usar o OmniSort, você concorda com estes termos. Se não concordar, desinstale o app e deixe de usá-lo.

2. O serviço

O OmniSort é uma ferramenta que classifica os arquivos de uma pasta por tipo, nome, data e critérios semelhantes e os move para subpastas. Seu uso é gratuito e não exige conta.

3. Projetado para a sua segurança

Nós o criamos para cumprir estas garantias:

  • Os arquivos só são movidos depois que você confere a prévia e toca em executar.
  • Nunca sobrescreve um arquivo com o mesmo nome. Se os nomes coincidirem, o arquivo é salvo com um novo nome ou ignorado.
  • Toda movimentação é registrada antes de acontecer, e a opção “Desfazer” do app pode devolver os arquivos ao lugar original.
  • O app para Android não tem nenhuma função que exclua arquivos. No app para Windows, excluir significa apenas enviar para a Lixeira.
  • O app para Android não se conecta à internet.

No entanto, esses são objetivos de projeto do software e não garantem o resultado em todas as situações.

4. Responsabilidades do usuário

  • Confira a prévia antes de mover e desmarque os arquivos que você não quer mover.
  • Recomendamos que você faça backup regular dos arquivos importantes.
  • Não organize arquivos de outras pessoas sem permissão e não use o app para descumprir a lei.
  • Se você organizar uma pasta usada por outro app (por exemplo, uma pasta de sincronização ou de backup), esse app pode deixar de encontrar seus arquivos. Deixe essas pastas de fora.

5. Condutas proibidas

  • Prejudicar o serviço ou os servidores
  • Enviar um número excessivo de requisições por meios automatizados
  • Alterar o software para fins maliciosos e distribuí-lo
