プライバシーポリシー

施行日: 2026-10-12

Projectteamforyou(以下「当方」)は、OmniSort(Windows アプリ、Android アプリ、ウェブサイト omnisort.win)を制作・運営しています。本ポリシーでは、当方がどのような情報をどのように取り扱うかを、ありのままにお伝えします。

1. ひとことで言うと

当方は、お客様のファイル、ファイル名、フォルダのパスを取得しません。アプリはすべての処理をお客様の端末の中で行います。

  • 会員登録やログインはなく、広告・分析用の外部 SDK も組み込んでいません。最上部の細い帯(「広告」と表示)は、Projectteamforyou の他のプログラム・アプリ・ゲームを紹介するリンクにすぎず、タップしたときだけ端末のウェブブラウザが開きます。
  • Android アプリにはインターネット権限がまったくないため、技術的に外部と通信できません。
  • ウェブサイトは、訪問数とダウンロード数を、日付と国(2 文字)だけで数えます。個人を特定できる情報は残しません。

2. 適用範囲

本ポリシーは、次のものに適用されます。

  • OmniSort for Windows
  • OmniSort for Android
  • 紹介用ウェブサイト omnisort.win
  • ダウンロード用アドレス dl.omnisort.win

3. アプリが端末内で取り扱う情報(Windows・Android 共通)

以下の情報は、整理の計画を立て、ファイルを移動し、元に戻すためだけに、端末の中で使われます。当方には送信されません。

  • 整理するフォルダ内のファイルの名前、サイズ、更新日時、拡張子 — 移動先を計算するために使います。
  • 画像ファイルの撮影日(EXIF) — 「日付フォルダ」オプションで撮影日を基準に選んだ場合にのみ読み取ります。
  • ファイルの先頭の数バイト — 拡張子と実際の内容が異なるファイル(例: 写真を装った実行ファイル)をお知らせするために読み取ります。内容は保存しません。
  • 操作履歴 — 移動したファイルの元の場所、新しい場所、名前。「元に戻す」のために、端末内のデータベースに保存されます。アプリから削除でき、アプリをアンインストールすると一緒に消えます。
  • 設定 — 言語、整理オプション、ご自身で作成したルール。

Android アプリは、お客様がシステムのフォルダ選択画面で自分で選んだフォルダにのみアクセスします。「すべてのファイルへのアクセス」を許可した場合も、その権限が及ぶフォルダの中で同じ方法でのみ動作します。

4. アプリが端末の外へ送るもの

  • Android アプリ: ありません。アプリにインターネット権限がありません。(設定で「プライバシーポリシー」などのリンクや最上部の帯をタップすると、端末のウェブブラウザが開きます。その後の通信はブラウザが行います。)
  • Windows アプリ: 新しいバージョンの確認(初期状態でオンで、設定からオフにできます)のために、1 日 1 回 https でバージョン一覧を取得します(GET 1 回)。アプリが送る情報はなく、リクエストにはアプリ名とバージョン番号が含まれます。お知らせの受信とダウンロード数の表示は初期状態でオフになっており、オンにすると同じ方法で公開ファイルを取得します。最上部の帯はアプリが何も取得せず、クリックすると既定のウェブブラウザが開きます。

いずれの場合も、ファイル名、パス、ファイル数が外部に送られることはありません。

5. ウェブサイト(omnisort.win)

  • Cookie: 当方は Cookie を設定しません。登録やログインもありません。
  • 累計アクセス数: ページを開くと、「日付」と「国コード(例: KR)」の 1 行分の回数だけが加算されます。IP アドレス、ブラウザ名、どこから来たかは保存しません。1 行は多数の人の合計なので、そこから個人をたどることはできません。
  • ダウンロード数: 「日付・国コード・形態(単一ファイル/フォルダ型/コマンドライン)・バージョン番号」ごとの回数だけを数えます。同様に、個人を特定することはありません。ロボットや先読みは数えません。
  • Cloudflare Web Analytics: どのページがどれだけ読まれているかを把握するために使います。Cookie や端末識別用のフィンガープリントは使わず、参照元・ブラウザの種類・国などの訪問統計が Cloudflare, Inc. に送られて処理されます。
  • ホスティング: サイトは GitHub Pages(GitHub, Inc.)で提供され、ダウンロードとサイトの前段は Cloudflare を経由します。これらの事業者は、サービスの運用とセキュリティのために、アクセス記録(IP アドレスなど)をそれぞれのポリシーに従って処理することがあります。当方はそれを個人の特定には使用しません。
  • オフライン保存: サイトをすばやく開けるように、ページの一部を訪問者のブラウザに保存(サービスワーカー)します。このデータは訪問者の端末の中にだけあります。

6. 第三者への提供と国外への移転

  • 当方は個人情報を販売せず、広告やマーケティングの目的で第三者に提供することもありません。
  • ウェブサイトをご利用になると、上記 5 の事業者(米国所在)のサーバーでアクセス情報が処理されることがあります。アプリをお使いの間、ファイルに関する情報が端末の外へ出ることはありません。

7. 保管と削除

  • アプリの情報はすべて端末内にあり、アプリで操作履歴を削除するか、アプリをアンインストールすることで、ご自身で消去できます。(Android: 設定 > アプリ > OmniSort > ストレージ > データを削除)
  • ウェブサイトの合計統計は、個人を特定できない集計値であり、サービスの運営のために保管します。
