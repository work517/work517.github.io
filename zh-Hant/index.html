怎麼用

分析 → 預覽 → 開始整理

三個步驟嚴守順序。分析沒結束就不碰任何檔案；沒有你的同意就不會移動。

1

分析

資料夾在背景讀取。隱藏檔、系統檔、符號連結以及 node_modules 這類資料夾都略過。中途隨時可以取消。

2

預覽

檔案、目前位置、新位置、分類理由都在同一張表。同名的會先標出來，勾選框由你決定。

3

開始整理

只移動你勾選的，並把每一次移動都記下來。結果不滿意，按一次[復原]就回到原樣。

功能

整理該有的功能，做扎實

你的規則永遠優先

用萬用字元、正規表示式、副檔名、大小或時間寫規則，並排定優先順序。合約* → Documents/Contracts。

看得見理由的分類

每一列都寫清楚依據：「副檔名 .pdf → 文件 · 檔名含『發票』→ Invoices」。

復原

以操作為單位記錄來源與目的地，再倒著還原。原位置若被別的檔案佔了，就略過而不是覆寫。

同名怎麼辦

同名就存成 報告 (1).pdf，或是略過。任何情況都不覆寫。

排除規則

不該動的東西可以用規則排除：*.crdownload、小於指定大小的檔案、整個資料夾。

定時整理

每天到時間，只分析也行，連移動一起做也行。schedule --install 一行就把工作排程也設好。

長路徑與非拉丁字元路徑

超過 260 個字元的路徑用 \\?\ 前綴處理，中文、日文、韓文路徑照常運作。

看穿偽裝的副檔名

「報價單.pdf」其實是執行檔，或是 發票.pdf.exe 這類雙副檔名，都會標上 ⚠。只有容易被假冒的副檔名才讀前 512 位元組。

尋找重複檔案

先比大小，再比頭尾各 64KB 的雜湊，最後比整個檔案，三步篩完只把副本送進資源回收筒。原檔依名稱判斷後保留。

紀錄

每次掃描和移動都留在 SQLite。operation_items 一列一筆：來源、目的地、狀態、理由、錯誤。

畫面不會卡住

掃描和移動都跑在工作執行緒上，1 萬個檔案掃描加分類約 5 秒。中途取消，紀錄照樣留著。

安全設計

不刪除。不覆寫。

整理工具一出錯，丟的就是資料。所以不能復原的動作，我們乾脆沒做。

  • 絕不自動永久刪除刪除只走資源回收筒。整理後空下來的資料夾也是送進回收筒，而不是直接刪掉。
  • 不覆寫（由核心保證）呼叫方式本身就是「目的地已存在就拒絕移動」。就算在「檢查完到移動」之間冒出一個檔案，也不會覆蓋別人的東西。
  • 就要移動前再確認一次預覽之後大小或修改時間變了、或變成連結的檔案，都不會被移動。
  • 系統資料夾一律不碰受保護的路徑在加入資料夾時就會被拒絕，掃描途中遇到也會略過。
  • 動手前全部攤開來源、目的地、有沒有同名，全攤開來，只處理你勾的。
  • 先記錄，後移動每一項都先寫進資料庫再移動。中途斷電也知道走到哪一步。
  • 正在寫入的檔案不動正在下載（.crdownload、.part）或剛剛更動過的檔案會自動略過。
  • 中斷了也能復原整理途中程式關掉了，下次啟動會查清移到哪一步，並整理成可以復原的狀態。
  • 不跟著連結走不會順著符號連結或 junction 跑到外面；目的地路徑中間夾著連結時直接拒絕。
  • 出不了根目錄規則裡不能寫 ..、絕對路徑或網路路徑；最終路徑一旦落在整理根目錄之外，就不會移動。

不能當作目的地的位置

  • C:\Windows
  • C:\Program Files
  • C:\Program Files (x86)
  • C:\ProgramData
  • %LOCALAPPDATA% · %APPDATA%
  • C:\$Recycle.Bin
  • System Volume Information
  • 磁碟機根目錄（C:\）
命令列 · 排程

可以掛到工作排程器的主控台版本

和視窗版用同一個資料庫、同一套規則。不加 --apply 就絕不會動任何檔案。

omnisort-cli.exe
# 登錄要整理的資料夾
omnisort-cli add "C:\Users\me\Downloads"

# 只看誰去哪（不移動）
omnisort-cli preview

# 加規則：合約進 Contracts，正在下載的排除
omnisort-cli rules add --name 合約 --glob "合約*" --target Documents/Contracts
omnisort-cli rules add --name 暫存 --glob "*.crdownload" --exclude

# 真的整理 · 復原 · 看紀錄
omnisort-cli run --apply --yes
omnisort-cli undo
omnisort-cli history

# 找重複 · 只留原檔，其餘進資源回收筒
omnisort-cli duplicates
omnisort-cli duplicates --trash

# 把預覽存成 CSV（Excel 可開）
omnisort-cli export plan.csv

# 每天 03:00 執行 — 一行連工作排程都設好
omnisort-cli config schedule_time 03:00
omnisort-cli schedule --install
omnisort-cli schedule --check
常見問題

開始前值得先知道的

會把檔案傳到網路上嗎？

不會。掃描、分類、移動、紀錄全都在這台電腦上完成。程式裡沒有任何網路功能，設定和紀錄只放在 %LOCALAPPDATA%\OmniSort\omnisort.db 這一個檔案。

整理完不滿意怎麼辦？

按[復原]，最近一次操作會以相反順序還原。也可以在紀錄裡挑一次舊操作來復原。如果原位置又出現同名檔案，那一項會被略過而不是覆寫，並且會告訴你哪些被略過、為什麼。

整理過的資料夾會被一再整理嗎？

OmniSort 建立的資料夾會留下記號，下次掃描自動略過。已經在正確位置的檔案也不會再進候選。

檔案被占用或沒有權限怎麼辦？

只把那一項記成失敗，其餘照常進行。原因在紀錄裡看得到，失敗的檔案仍在原處。

需要安裝嗎？

下載一個 OmniSort.exe 直接執行就好。不用系統管理員權限，也不寫登錄檔。想移除時，刪掉 exe 和上面那個資料庫檔案，就什麼都不留。
