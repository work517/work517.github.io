怎麼用

分析 → 預覽 → 開始整理

三個步驟嚴守順序。分析沒結束就不碰任何檔案；沒有你的同意就不會移動。

1

分析

資料夾在背景讀取。隱藏檔、系統檔、符號連結以及 node_modules 這類資料夾都略過。中途隨時可以取消。

2

預覽

檔案、目前位置、新位置、分類理由都在同一張表。同名的會先標出來，勾選框由你決定。

3

開始整理

只移動你勾選的，並把每一次移動都記下來。結果不滿意，按一次[復原]就回到原樣。

功能

整理該有的功能，做扎實

你的規則永遠優先

用萬用字元、正規表示式、副檔名、大小或時間寫規則，並排定優先順序。合約* → Documents/Contracts。

看得見理由的分類

每一列都寫清楚依據：「副檔名 .pdf → 文件 · 檔名含『發票』→ Invoices」。

復原

以操作為單位記錄來源與目的地，再倒著還原。原位置若被別的檔案佔了，就略過而不是覆寫。

同名怎麼辦

同名就存成 報告 (1).pdf，或是略過。任何情況都不覆寫。

排除規則

不該動的東西可以用規則排除：*.crdownload、小於指定大小的檔案、整個資料夾。

定時整理

每天到時間，只分析也行，連移動一起做也行。schedule --install 一行就把工作排程也設好。

長路徑與非拉丁字元路徑

超過 260 個字元的路徑用 \\?\ 前綴處理，中文、日文、韓文路徑照常運作。

看穿偽裝的副檔名

「報價單.pdf」其實是執行檔，或是 發票.pdf.exe 這類雙副檔名，都會標上 ⚠。只有容易被假冒的副檔名才讀前 512 位元組。

尋找重複檔案

先比大小，再比頭尾各 64KB 的雜湊，最後比整個檔案，三步篩完只把副本送進資源回收筒。原檔依名稱判斷後保留。

紀錄

每次掃描和移動都留在 SQLite。operation_items 一列一筆：來源、目的地、狀態、理由、錯誤。

規則預設集

一次加入給學生、上班族、開發者、攝影/設計用的規則組。加入前先告訴你什麼會去哪裡，你自己寫的規則永遠優先。

空間占用

以唯讀方式列出大型檔案、很久沒動過的檔案、各分類占用和磁碟剩餘空間。清理的只有你選取的檔案，而且只進資源回收筒。

按月統計

在管理面板裡查看每月整理量、整體成功率，以及移至資源回收筒釋出的空間。規則可以匯出成 JSON，分享給其他電腦。

畫面不會卡住

掃描和移動都跑在工作執行緒上，1 萬個檔案掃描加分類約 5 秒。中途取消，紀錄照樣留著。

安全設計

不刪除。不覆寫。

整理工具一出錯，丟的就是資料。所以不能復原的動作，我們乾脆沒做。

  • 絕不自動永久刪除刪除只走資源回收筒。整理後空下來的資料夾也是送進回收筒，而不是直接刪掉。
  • 不覆寫（由核心保證）呼叫方式本身就是「目的地已存在就拒絕移動」。就算在「檢查完到移動」之間冒出一個檔案，也不會覆蓋別人的東西。
  • 就要移動前再確認一次預覽之後大小或修改時間變了、或變成連結的檔案，都不會被移動。
  • 系統資料夾一律不碰受保護的路徑在加入資料夾時就會被拒絕，掃描途中遇到也會略過。
  • 動手前全部攤開來源、目的地、有沒有同名，全攤開來，只處理你勾的。
  • 先記錄，後移動每一項都先寫進資料庫再移動。中途斷電也知道走到哪一步。
  • 正在寫入的檔案不動正在下載（.crdownload、.part）或剛剛更動過的檔案會自動略過。
  • 中斷了也能復原整理途中程式關掉了，下次啟動會查清移到哪一步，並整理成可以復原的狀態。
  • 不跟著連結走不會順著符號連結或 junction 跑到外面；目的地路徑中間夾著連結時直接拒絕。
  • 出不了根目錄規則裡不能寫 ..、絕對路徑或網路路徑；最終路徑一旦落在整理根目錄之外，就不會移動。

不能當作目的地的位置

  • C:\Windows
  • C:\Program Files
  • C:\Program Files (x86)
  • C:\ProgramData
  • %LOCALAPPDATA% · %APPDATA%
  • C:\$Recycle.Bin
  • System Volume Information
  • 磁碟機根目錄（C:\）
已經踩過的坑

這份清單不是想出來的，是撞上去才有的

移動檔案的程式之所以危險，不是因為功能不夠，而是檔案會在沒人想到的地方消失。下面每一條都是我們真的撞上並修好的。

  • 有些檔案進不了資源回收筒網路或卸除式磁碟上的檔案、比資源回收筒還大的檔案、關閉了資源回收筒的磁碟。這時 Windows 會不詢問就永久刪除。我們會先確認，做不到就原樣保留並記下原因。
  • 移動中拔掉隨身碟，兩份都會沒跨磁碟移動，其實是先複製再刪除原檔。我們會等複製真正寫入磁碟之後才刪原檔。這樣會慢一些，但這才是對的。
  • 資料夾可能其實指向別處連接點、8.3 短檔名、管理共用(\\host\C$)、裝置路徑。繞回受保護資料夾的四條路，逐一封堵。
  • 剛選好的名字，可能在那一瞬被搶走剛選定一個不重名的新名字，另一個程式就可能用這個名字建檔。我們的呼叫方式讓核心直接拒絕，所以即使如此也不會覆蓋別人的檔案。
  • 來自 Mac 的中韓文檔名並不是同一串字元螢幕上同樣顯示 계약서.pdf，但儲存形式不同，規則會悄悄錯過。我們只在比較時對齊——檔名本身絕不改動。
  • 能被改的紀錄不算紀錄每次整理都會在前一筆紀錄之上蓋下封印。改一行、刪一筆、塞進一筆假的，後面全部對不上，立刻暴露。

不是嘴上說說，是建置在把關

  • 不永久刪除
  • 不覆蓋
  • 移動前再次確認
  • 拒絕受保護路徑
  • 先紀錄，後移動
  • 對外只有一條出口

這六條，只要有程式碼違反，發佈本身就會被攔下。

你可以自己查。[管理]介面會顯示這台電腦實際向外發出的次數。剛裝好時顯示「從未發生」。

命令列 · 排程

可以掛到工作排程器的主控台版本

和視窗版用同一個資料庫、同一套規則。不加 --apply 就絕不會動任何檔案。

omnisort-cli.exe
# 登錄要整理的資料夾
omnisort-cli add "C:\Users\me\Downloads"

# 只看誰去哪（不移動）
omnisort-cli preview

# 加規則：合約進 Contracts，正在下載的排除
omnisort-cli rules add --name 合約 --glob "合約*" --target Documents/Contracts
omnisort-cli rules add --name 暫存 --glob "*.crdownload" --exclude

# 真的整理 · 復原 · 看紀錄
omnisort-cli run --apply --yes
omnisort-cli undo
omnisort-cli history

# 找重複 · 只留原檔，其餘進資源回收筒
omnisort-cli duplicates
omnisort-cli duplicates --trash

# 查看大型檔案、舊檔案、磁碟空間（唯讀）
omnisort-cli space --old-days 365

# 查看規則預設集 · 加入學生用規則組
omnisort-cli rules preset
omnisort-cli rules preset student

# 把預覽存成 CSV（Excel 可開）
omnisort-cli export plan.csv

# 每天 03:00 執行 — 一行連工作排程都設好
omnisort-cli config schedule_time 03:00
omnisort-cli schedule --install
omnisort-cli schedule --check
比較

比移動更難的，是移錯了的時候

盯著資料夾、依規則立刻移動的工具很快，但什麼去了哪裡，要等移完才知道。OmniSort 把順序倒了過來。

項目 手動整理 依規則直接移動的工具 OmniSort
移動前看到去向 自己判斷 移完才知道 每個檔案的去向和理由
移錯了的時候 全憑記憶 因工具而異 以操作為單位整批復原，舊操作也行

清理重複與大型檔案 在檔案總管裡一個個來 需要另找工具 一個程式搞定，只進資源回收筒
網路與帳號 不需要 因工具而異 不需要，預設什麼都不外傳

如果防毒軟體擋下

單檔的 OmniSort.exe 把程式和整個 Qt 函式庫壓縮後放在自身內部。執行時再解開使用。

部分防毒軟體的機器學習檢查會把這讀成「自行解壓並執行」。因此有時會以 Wacatac、Dropper.Agent 這類通用名稱報出。這是用 Python 撰寫的程式常見的誤判。

先比對上面的 SHA-256，確認拿到的檔案與我們發布的一致。也請從檔案內容查看發行者是否為 PROJECTTEAMFORYOU。

兩項都對的話，請試試資料夾版 zip。那是另一個檔案，裡面沒有壓縮成塊的內容，判定可能不同。

仍被擋下，請把防毒軟體名稱和顯示的名稱寄到 projectteamforyou@gmail.com。誤判申訴由我們來提交。

常見問題

開始前值得先知道的

會把檔案傳到網路上嗎？

不會。掃描、分類、移動、紀錄全都在這台電腦上完成，檔名和路徑都不會外流。設定和紀錄只放在 %LOCALAPPDATA%\OmniSort\omnisort.db 這一個檔案。

完全不連網嗎？

預設一次都不用。只有你在管理面板裡親自開啟檢查新版、公告或下載次數時才會取得，而且那時也不送出任何檔案資訊（檢查新版時只帶上版本號）。會送出什麼，那個面板上連位址都寫得清清楚楚。

會統計下載次數嗎？

按下下載按鈕時，我們的伺服器只記錄日期、兩碼國家代碼與所取得的版本形式。不記錄 IP 位址、瀏覽器名稱與來源頁面。每一列都是許多人的加總，無法據此回推到某個人。程式本身沒有改變 — 只有你在管理畫面開啟的功能才會連網。

免費嗎？

是的。免費使用，不需要帳號，也不用付費。預設也沒有廣告。如果你在管理面板裡開啟了接收公告，收到廣告性質的消息時，會標明「廣告」再顯示。

空間占用會刪除檔案嗎？

不會。空間占用只讀取。只有你在清單裡親自選取並確認的檔案才會進資源回收筒，而且可以從資源回收筒還原。網路磁碟機或 USB 隨身碟等卸除式磁碟機上的檔案、比資源回收筒還大的檔案這類放不進資源回收筒的，不會移至資源回收筒，而是提示你。

整理完不滿意怎麼辦？

按[復原]，最近一次操作會以相反順序還原。也可以在紀錄裡挑一次舊操作來復原。如果原位置又出現同名檔案，那一項會被略過而不是覆寫，並且會告訴你哪些被略過、為什麼。

整理過的資料夾會被一再整理嗎？

OmniSort 建立的資料夾會留下記號，下次掃描自動略過。已經在正確位置的檔案也不會再進候選。

檔案被占用或沒有權限怎麼辦？

只把那一項記成失敗，其餘照常進行。原因在紀錄裡看得到，失敗的檔案仍在原處。

需要安裝嗎？

下載一個 OmniSort.exe 直接執行就好。不用系統管理員權限，也不寫登錄檔。想移除時，刪掉 exe 和上面那個資料庫資料夾即可。如果開啟過定時整理，請先用 omnisort-cli schedule --uninstall 刪掉工作排程器裡的登錄。
