隱私權政策

生效日期: 2026-10-12

Projectteamforyou（以下稱「我們」）開發並營運 OmniSort（Windows 應用程式、Android 應用程式及網站 omnisort.win）。本政策將如實說明我們會處理哪些資訊，以及如何處理。

1. 一句話摘要

我們不會取得您的檔案、檔案名稱或資料夾路徑。應用程式的所有處理都在您自己的裝置上完成。

  • 沒有註冊與登入，也未內建任何用於廣告或分析的第三方 SDK。最上方的細長橫條（標示為「廣告」）只是一個連結，用來介紹 Projectteamforyou 的其他程式、應用程式與遊戲；只有在您點選時，才會開啟裝置上的網頁瀏覽器。
  • Android 應用程式完全沒有網際網路權限，因此在技術上無法與外部通訊。
  • 網站只會依日期與國家（兩個字母）統計造訪與下載次數，不會留下任何可識別您身分的資訊。

2. 適用範圍

本政策適用於下列項目：

  • OmniSort for Windows
  • OmniSort for Android
  • 介紹網站 omnisort.win
  • 下載網址 dl.omnisort.win

3. 應用程式在裝置內處理的資訊（Windows 與 Android 通用）

下列資訊僅在裝置內用於規劃整理、移動檔案與復原，不會傳送給我們。

  • 您選擇整理的資料夾內檔案的名稱、大小、修改時間與副檔名——用來計算檔案該移到哪裡。
  • 相片的拍攝日期（EXIF）——只有在「日期資料夾」選項中選擇以拍攝日期為依據時才會讀取。
  • 檔案開頭的幾個位元組——用來提醒您副檔名與實際內容不符的檔案（例如偽裝成相片的執行檔）。不會儲存檔案內容。
  • 作業紀錄——已移動檔案的原位置、新位置與名稱。為了讓您能「復原」，這些資料會儲存在裝置內的資料庫中。您可以在應用程式中清除，解除安裝應用程式時也會一併消失。
  • 設定——語言、整理選項與您自訂的規則。

Android 應用程式只會存取您在系統資料夾選擇器中親自選取的資料夾。即使您允許「所有檔案存取權」，也僅會以相同方式，在該權限所涵蓋的資料夾中運作。

4. 應用程式傳送到裝置外的資訊

  • Android 應用程式：沒有。應用程式沒有網際網路權限。（在設定中點選「隱私權政策」之類的連結或最上方的橫條時，會開啟裝置的網頁瀏覽器，之後的通訊由瀏覽器負責。）
  • Windows 應用程式：為了檢查新版本（預設開啟，可在設定中關閉），每天會透過 https 取得一次版本清單（一次 GET 請求）。應用程式不會傳送任何資訊，請求中僅包含應用程式名稱與版本號碼。接收公告與查看下載次數預設為關閉，開啟後會以相同方式取得公開檔案。最上方的橫條不會取得任何內容；點選後會開啟預設的網頁瀏覽器。

無論哪一種情況，檔案名稱、路徑與數量都不會傳送出去。

5. 網站（omnisort.win）

  • Cookie：我們不會設定 Cookie，也沒有註冊與登入。
  • 累計造訪數：開啟頁面時，只會為「日期」與「國家代碼（例如 KR）」這一行的次數加一。不會儲存 IP 位址、瀏覽器名稱或來源網站。一行紀錄是許多人的總和，因此無法從中追查到個人。
  • 下載次數：只依「日期、國家代碼、形式（單一檔案／資料夾版／命令列）、版本號碼」計算次數。同樣不會識別個人。機器人與預先擷取不計入。
  • Cloudflare Web Analytics：用來了解各頁面被閱讀的情形。不使用 Cookie 與裝置指紋，但來源管道、瀏覽器類型、國家等造訪統計資料會傳送至 Cloudflare, Inc. 並由其處理。
  • 代管：網站由 GitHub Pages（GitHub, Inc.）提供，下載與網站前端則經由 Cloudflare。這些業者為了營運與安全，可能依各自的政策處理連線紀錄（如 IP 位址）。我們不會將這些紀錄用於識別個人。
  • 離線儲存：為了讓網站更快開啟，網站會將部分頁面儲存在訪客的瀏覽器中（Service Worker）。這些資料只存在訪客的裝置內。

6. 提供給第三方與跨國傳輸

  • 我們不會販售個人資料，也不會為了廣告或行銷目的提供給第三方。
  • 使用網站時，連線資訊可能會在上述第 5 項中業者（位於美國）的伺服器上處理。使用應用程式期間，與檔案相關的資訊不會離開您的裝置。

7. 保存與刪除

  • 應用程式中的資訊全部保存在裝置上，您可以在應用程式中清除作業紀錄，或解除安裝應用程式，自行刪除。（Android：設定 > 應用程式 > OmniSort > 儲存空間 > 清除資料）
  • 網站的合計統計是無法識別個人的彙總數字，我們為了營運服務而保存。

8. 使用者的權利與聯絡方式

我們實際上幾乎不持有任何個人資料。即使如此，如果您想查詢、更正、刪除，或要求停止處理，請寄信至下方信箱。我們確認後會立即回覆。

個人資料保護負責單位：Projectteamforyou · projectteamforyou@gmail.com

9. 兒童

OmniSort 並非以兒童為對象的服務，我們不會蒐集兒童的個人資料。

10. 本政策的變更

內容有所變更時，我們會在本頁面公布新版本及新的生效日期。重大變更也會在介紹頁面的首頁公告。
