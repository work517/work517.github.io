隐私政策

生效日期: 2026-10-12

Projectteamforyou(以下简称“我们”)开发并运营 OmniSort(Windows 应用、Android 应用和网站 omnisort.win)。本政策如实说明我们会处理哪些信息,以及如何处理。

1. 一句话概述

我们不会获取您的文件、文件名和文件夹路径。应用的所有处理都在您的设备内完成。

  • 没有注册和登录,也没有接入用于广告或分析的第三方 SDK。顶部的细条(标有“广告”)只是一个链接,用来介绍 Projectteamforyou 的其他程序、应用和游戏;只有在您点按时,才会打开设备上的网页浏览器。
  • Android 应用完全没有联网权限,因此在技术上无法与外部通信。
  • 网站只按日期和国家(两个字母)统计访问次数和下载次数,不会留下任何可识别您身份的信息。

2. 适用范围

本政策适用于以下内容:

  • OmniSort for Windows
  • OmniSort for Android
  • 介绍网站 omnisort.win
  • 下载地址 dl.omnisort.win

3. 应用在设备内处理的信息(Windows 和 Android 通用)

以下信息仅在设备内用于制定整理计划、移动文件和撤销操作,不会发送给我们。

  • 您要整理的文件夹中文件的名称、大小、修改时间和扩展名 — 用于计算文件应移动到哪里。
  • 图片文件的拍摄日期(EXIF) — 仅当您在“日期文件夹”选项中选择以拍摄日期为依据时才会读取。
  • 文件开头的几个字节 — 用于提醒您扩展名与实际内容不符的文件(例如伪装成照片的可执行文件)。不会保存文件内容。
  • 操作记录 — 已移动文件的原位置、新位置和名称。为了支持“撤销”,这些记录保存在设备内的数据库中。您可以在应用中清除,卸载应用时也会一并删除。
  • 设置 — 语言、整理选项和您自己创建的规则。

Android 应用只会访问您在系统文件夹选择器中亲自选择的文件夹。即使您允许“所有文件访问权限”,应用也同样只在该权限所涉及的文件夹内按此方式运行。

4. 应用向设备外发送的内容

  • Android 应用:没有。应用没有联网权限。(在设置中点击“隐私政策”等链接或顶部的细条时,会打开设备的网页浏览器,之后的通信由浏览器完成。)
  • Windows 应用:为检查新版本(默认开启,可在设置中关闭),每天通过 https 获取一次版本列表(一次 GET 请求)。应用不发送任何信息,请求中包含应用名称和版本号。接收公告和查看下载次数默认关闭,开启后会以同样的方式获取公开文件。顶部的细条不会获取任何内容;点击它会打开默认的网页浏览器。

无论哪种情况,文件名、路径和文件数量都不会发送到外部。

5. 网站(omnisort.win)

  • Cookie:我们不设置 Cookie。也没有注册和登录。
  • 累计访问次数:打开页面时,只会为“日期”和“国家代码(例如 KR)”这一行的次数加一。不会保存 IP 地址、浏览器名称和来源。一行是许多人的合计,因此无法据此追溯到某个人。
  • 下载次数:只按“日期、国家代码、形式(单个文件/文件夹版/命令行)、版本号”统计次数。同样不会识别个人。机器人和预取不计入。
  • Cloudflare Web Analytics:用于了解哪些页面被阅读以及阅读量。不使用 Cookie 和设备识别指纹,来源渠道、浏览器类型、国家等访问统计信息会传送给 Cloudflare, Inc. 并由其处理。
  • 托管:网站通过 GitHub Pages(GitHub, Inc.)提供,下载和网站前端经由 Cloudflare。为了服务运营和安全,这些服务商可能按各自的政策处理访问记录(如 IP 地址)。我们不会将其用于识别个人。
  • 离线存储:为了让网站更快打开,网站会把部分页面保存(Service Worker)在访问者的浏览器中。这些数据只存在于访问者的设备内。

6. 向第三方提供与跨境传输

  • 我们不出售个人信息,也不会出于广告或营销目的向第三方提供。
  • 使用网站时,访问信息可能会在上文第 5 项所述服务商(位于美国)的服务器上处理。使用应用期间,与文件有关的信息不会离开您的设备。

7. 保存与删除

  • 应用中的信息全部保存在设备内,您可以在应用中清除操作记录,或卸载应用来自行删除。(Android:设置 > 应用 > OmniSort > 存储 > 清除数据)
  • 网站的合计统计是无法识别个人的汇总数字,为运营服务而保留。

8. 您的权利与联系方式

我们实际上不持有任何个人信息。即便如此,如果您希望查阅、更正、删除或停止处理,请发送邮件至下方地址。我们确认后会及时答复。

个人信息保护负责人:Projectteamforyou · projectteamforyou@gmail.com

9. 儿童

OmniSort 不是面向儿童的服务,我们不会收集儿童的个人信息。

10. 本政策的变更

内容发生变化时,我们会连同新的生效日期一并发布在本页面。重要变更还会在介绍页首页公告。
