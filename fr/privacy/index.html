Politique de confidentialité

En vigueur depuis le: 2026-10-12

Projectteamforyou (« nous ») conçoit et exploite OmniSort (l’application Windows, l’application Android et le site web omnisort.win). La présente politique décrit en toute transparence les informations que nous traitons et la manière dont nous les traitons.

1. En une phrase

Nous ne prenons ni vos fichiers, ni leurs noms, ni les chemins de vos dossiers. Les applications effectuent tous leurs traitements sur votre appareil.

  • Il n’y a ni inscription ni connexion, et nous n’avons intégré aucun SDK externe de publicité ou d’analyse. La fine bande en haut (portant la mention « Publicité ») n’est qu’un lien qui présente d’autres programmes, applications et jeux de Projectteamforyou ; le navigateur web de votre appareil ne s’ouvre que si vous la touchez.
  • L’application Android ne dispose d’aucune autorisation Internet : techniquement, elle ne peut pas communiquer avec l’extérieur.
  • Le site web compte les visites et les téléchargements uniquement par date et par pays (deux lettres). Il ne conserve aucune information permettant de vous identifier.

2. Champ d’application

La présente politique s’applique à :

  • OmniSort pour Windows
  • OmniSort pour Android
  • Le site de présentation omnisort.win
  • L’adresse de téléchargement dl.omnisort.win

3. Informations que les applications traitent sur votre appareil (Windows et Android)

Les informations ci-dessous sont utilisées uniquement sur votre appareil, pour établir le plan de rangement, déplacer les fichiers et les remettre en place. Elles ne nous sont pas transmises.

  • Le nom, la taille, l’heure de modification et l’extension des fichiers présents dans les dossiers que vous choisissez de ranger : ces éléments servent à calculer la destination de chaque fichier.
  • La date de prise de vue des images (EXIF) : elle n’est lue que si vous choisissez la date de prise de vue comme critère de l’option « Dossiers par date ».
  • Les premiers octets d’un fichier : ils sont lus pour vous avertir lorsque l’extension d’un fichier ne correspond pas à son contenu réel (par exemple, un programme exécutable qui se fait passer pour une photo). Le contenu n’est pas enregistré.
  • L’historique des opérations : l’emplacement d’origine, le nouvel emplacement et le nom des fichiers déplacés. Il est enregistré dans une base de données sur votre appareil afin de permettre l’annulation. Vous pouvez l’effacer depuis l’application, et il disparaît avec elle lorsque vous la désinstallez.
  • Les réglages : la langue, les options de rangement et les règles que vous avez créées.

L’application Android n’accède qu’aux dossiers que vous avez choisis vous-même dans le sélecteur de dossiers du système. Si vous accordez l’autorisation « Accès à tous les fichiers », elle fonctionne toujours de la même manière, uniquement dans les dossiers couverts par cette autorisation.

4. Ce que les applications envoient hors de votre appareil

  • Application Android : rien. L’application n’a pas d’autorisation Internet. (Si vous touchez un lien tel que « Politique de confidentialité » dans les réglages, ou la bande en haut, le navigateur web de votre appareil s’ouvre ; les échanges qui suivent relèvent du navigateur.)
  • Application Windows : pour la recherche de nouvelle version (activée par défaut et désactivable dans les réglages), elle récupère une fois par jour la liste des versions via https (une seule requête GET). L’application n’envoie aucune information ; la requête contient le nom de l’application et son numéro de version. La réception des annonces et l’affichage du nombre de téléchargements sont désactivés par défaut ; si vous les activez, ils récupèrent des fichiers publics de la même manière. La bande en haut ne récupère rien ; si vous cliquez dessus, votre navigateur web par défaut s’ouvre.

Dans aucun cas, les noms de fichiers, les chemins ou les quantités ne sont envoyés à l’extérieur.

5. Le site web (omnisort.win)

  • Cookies : nous ne déposons aucun cookie. Il n’y a ni inscription ni connexion.
  • Compteur de visites : lorsque vous ouvrez une page, seul le total d’une ligne composée de la date et d’un code pays (par exemple KR) est incrémenté. Votre adresse IP, le nom de votre navigateur et la page d’où vous venez ne sont pas enregistrés. Une ligne correspond à la somme de nombreuses personnes ; il est donc impossible d’en retrouver une seule.
  • Compteur de téléchargements : nous comptons uniquement par date, code pays, forme (fichier unique / version en dossier / ligne de commande) et numéro de version. Comme pour les visites, il n’identifie aucune personne. Les robots et les préchargements ne sont pas comptés.
  • Cloudflare Web Analytics : utilisé pour savoir quelles pages sont lues et dans quelle mesure. Il n’utilise ni cookies ni empreinte numérique de l’appareil ; des statistiques de visite telles que la provenance, le type de navigateur et le pays sont transmises à Cloudflare, Inc. et traitées par cette société.
  • Hébergement : le site est diffusé par GitHub Pages (GitHub, Inc.), et les téléchargements ainsi que la façade du site passent par Cloudflare. Ces prestataires peuvent traiter des journaux de connexion (adresses IP, etc.) selon leurs propres politiques, pour l’exploitation et la sécurité du service. Nous n’utilisons pas ces données pour identifier qui que ce soit.
  • Stockage hors ligne : pour que le site s’ouvre rapidement, une partie des pages est enregistrée dans le navigateur du visiteur (service worker). Ces données restent uniquement sur l’appareil du visiteur.

6. Communication à des tiers et transferts à l’étranger

  • Nous ne vendons pas de données personnelles et nous ne les communiquons pas à des tiers à des fins de publicité ou de marketing.
  • Lorsque vous utilisez le site web, les informations de connexion peuvent être traitées sur les serveurs des prestataires mentionnés à l’article 5 (situés aux États-Unis). Pendant que vous utilisez les applications, les informations relatives à vos fichiers ne quittent pas votre appareil.

7. Conservation et suppression

  • Toutes les informations des applications se trouvent sur votre appareil. Vous pouvez les supprimer vous-même en effaçant l’historique des opérations dans l’application ou en désinstallant celle-ci. (Android : Paramètres > Applications > OmniSort > Stockage > Effacer les données)
  • Les totaux statistiques du site web sont des chiffres agrégés qui ne permettent d’identifier personne ; nous les conservons pour assurer le fonctionnement du service.

8. Vos droits et comment nous contacter

Nous ne détenons pratiquement aucune donnée personnelle. Si vous souhaitez malgré tout y accéder, les rectifier, les supprimer ou demander l’arrêt de leur traitement, écrivez-nous à l’adresse ci-dessous. Après vérification, nous vous répondrons sans délai.

Contact pour la protection des données personnelles : Projectteamforyou · projectteamforyou@gmail.com

9. Enfants

OmniSort n’est pas un service destiné aux enfants, et nous ne collectons pas de données personnelles concernant des enfants.

10. Modification de la présente politique

Si cette politique change, nous publierons ici la nouvelle version avec une nouvelle date d’entrée en vigueur. Les changements importants sont aussi annoncés en haut de la page d’accueil.
