2. The service

OmniSort is a tool that sorts the files in a folder by type, name, date and similar criteria and moves them into subfolders. It is free to use and needs no account.

3. Designed for safety

We built it to keep these promises:

  • Files move only after you have checked the preview and pressed the run button.
  • It never overwrites a file of the same name. If names collide, it saves under a new name or skips the file.
  • Every move is recorded first, and the app’s “Undo” can put it back where it was.
  • The Android app has no function that deletes files. Deleting in the Windows app only sends files to the Recycle Bin.
  • The Android app does not connect to the internet.

These are design goals of the software, however, and not a guarantee of the result in every situation.

4. Your responsibilities
