## 이 저장소에 있는 것

만들어진 정적 페이지뿐입니다. OmniSort 의 소스 코드는 여기 없습니다.

```
index.html          한국어
<언어코드>/          나머지 11개 언어
assets/             파비콘 · PWA 아이콘 · 언어별 공유 카드
sw.js               서비스 워커 (한 번 연 페이지는 인터넷 없이도 열립니다)
robots.txt          검색엔진
sitemap.xml         12개 언어 + x-default
notices.json        앱이 받아 가는 공지 (기본으로 꺼져 있습니다)
```

페이지는 이미지를 안에 품고 있어서, `index.html` 하나만 따로 열어도 그대로 보입니다.

## OmniSort 가 무엇인가

Windows 용 파일 정리 도구입니다. Downloads 같은 폴더를 훑어 확장자·파일명·날짜·
크기로 분류하고, **옮기기 전에 한 줄마다 "왜 이 폴더인지"를 보여줍니다.**
승인한 것만 옮기고, 전부 되돌릴 수 있습니다.

- 영구 삭제가 없습니다. 지우는 동작은 휴지통으로만 갑니다.
- 덮어쓰지 않습니다. 대상이 있으면 커널이 이동을 거절합니다.
- 모든 처리는 그 PC 안에서 일어납니다. 새 판 확인과 공지 받기만 바깥과
  이야기하고, 둘 다 기본으로 꺼져 있습니다.

## 공지 파일

`notices.json` 을 고치면 앱의 [관리자 > 공지] 에 뜹니다. `kind` 가 `promo` 면
화면에 **광고**라고 적혀 나갑니다. 소식인 척하는 광고는 쓰지 않습니다.
