동작 방식

분석 → 미리보기 → 정리 실행

세 단계는 순서를 지킵니다. 분석이 끝나기 전에는 어떤 파일도 건드리지 않고, 승인 없이 이동하지 않습니다.

1

분석

대상 폴더를 백그라운드에서 훑습니다. 숨김·시스템 파일, 심볼릭 링크, node_modules 같은 폴더는 건너뜁니다. 진행 중 언제든 취소할 수 있습니다.

2

미리보기

파일 / 현재 위치 / 새 위치 / 분류 이유가 한 표에 나옵니다. 이름이 겹치는 항목은 미리 표시되고, 체크박스로 원하는 것만 고릅니다.

3

정리 실행

선택한 항목만 옮기고 모든 이동을 기록합니다. 결과가 마음에 들지 않으면 [되돌리기] 한 번으로 원래 자리로 돌아갑니다.

기능

정리 도구에 필요한 것만, 제대로

내 규칙이 항상 먼저

와일드카드·정규식·확장자·크기·기간으로 규칙을 만들고 우선순위를 줍니다. 계약* → Documents/Contracts.

이유가 보이는 분류

“확장자 .pdf → 문서 · 파일명 ‘인보이스’ → Invoices”처럼 판단 근거를 행마다 적어둡니다.

되돌리기

작업 단위로 원본↔대상을 기록해 역순으로 복구합니다. 원래 자리에 다른 파일이 생겼으면 덮어쓰지 않고 건너뜁니다.

이름 충돌 처리

겹치면 보고서 (1).pdf로 저장하거나 건너뜁니다. 덮어쓰기는 어떤 경우에도 하지 않습니다.

제외 규칙

*.crdownload, 최소 크기 미만, 특정 폴더처럼 손대면 안 되는 것들을 규칙으로 빼둡니다.

예약 정리

매일 지정한 시각에 분석만 하거나, 이동까지 자동으로. schedule --install 한 줄이면 작업 스케줄러 등록까지 끝납니다.

긴 경로·한글 경로

260자를 넘는 경로는 \\?\ 접두사로 처리하고, 한글·일본어·중국어 경로를 그대로 다룹니다.

확장자 위장 탐지

‘견적서.pdf’ 인데 내용이 실행 파일이거나 송장.pdf.exe 같은 이중 확장자를 ⚠로 표시합니다. 속을 만한 확장자만 앞 512바이트를 읽습니다.

중복 파일 찾기

크기 → 앞뒤 64KB 해시 → 전체 해시 3단계로 걸러, 사본만 골라 휴지통으로. 원본은 이름으로 판단해 남깁니다.

작업 로그

모든 스캔과 이동이 SQLite에 남습니다. operation_items에 원본·대상·상태·이유·오류가 한 줄씩.

규칙 프리셋

학생·직장인·개발자·사진/디자인용 규칙 묶음을 한 번에 넣습니다. 넣기 전에 무엇이 어디로 가는지 보여 주고, 직접 만든 규칙이 늘 먼저 적용됩니다.

공간 찾기

큰 파일, 오래 안 건드린 파일, 분류별 용량과 디스크 남은 공간을 읽기만 해서 보여 줍니다. 치우는 것은 고른 파일만, 휴지통으로.

달마다 보는 운영 통계

관리자 화면에서 달마다 정리한 양과 전체 성공률, 휴지통으로 비운 용량을 봅니다. 규칙은 JSON 으로 내보내 다른 PC 와 나눌 수 있습니다.

끊기지 않는 UI

스캔과 이동은 워커 스레드에서 돌고, 1만 파일 스캔·분류에 약 5초. 중간에 취소해도 기록은 남습니다.

안전 설계

지우지 않습니다. 덮어쓰지 않습니다.

파일 정리 도구의 실패는 곧 데이터 손실입니다. 그래서 되돌릴 수 없는 동작은 아예 넣지 않았습니다.

  • 자동 영구삭제 없음삭제는 휴지통으로만. 정리 후 남은 빈 폴더도 지우지 않고 휴지통으로 보냅니다.
  • 덮어쓰기 없음 (커널이 보장)대상이 있으면 이동 자체가 거절되도록 호출합니다. ‘확인 후 이동’ 사이에 파일이 생겨도 남의 파일을 덮지 않습니다.
  • 이동 직전 재확인미리보기 이후 크기·수정시각이 달라졌거나 링크로 바뀐 파일은 옮기지 않습니다.
  • 시스템 폴더 차단보호 경로는 대상 추가 단계에서 거절하고, 스캔 중 만나도 건너뜁니다.
  • 이동 전 전체 공개원본·대상·충돌 여부를 모두 보여주고, 체크한 항목만 처리합니다.
  • 기록 먼저, 이동 나중각 항목을 DB에 기록한 뒤 옮깁니다. 중간에 꺼져도 어디까지 됐는지 남습니다.
  • 쓰는 중인 파일은 그대로내려받는 중(.crdownload, .part)이거나 방금 바뀐 파일은 자동으로 건너뜁니다.
  • 중단돼도 되돌릴 수 있음정리 도중 프로그램이 꺼져도, 다음 실행에서 어디까지 옮겼는지 확인해 되돌릴 수 있게 정리합니다.
  • 링크는 따라가지 않음심볼릭 링크와 정션 밖으로 나가지 않고, 대상 폴더 경로에 링크가 끼어 있으면 거절합니다.
  • 경로 탈출 차단규칙에 ..·절대경로·네트워크 경로를 쓸 수 없고, 최종 경로가 정리 루트 밖이면 옮기지 않습니다.

겪고 고친 것

이 목록은 만든 게 아니라, 겪은 것입니다

파일을 옮기는 프로그램이 위험한 이유는 기능이 모자라서가 아니라, 아무도 예상하지 않은 자리에서 파일이 사라지기 때문입니다. 아래는 전부 실제로 겪고 고친 것들입니다.

  • 휴지통에 안 들어가는 파일이 있습니다네트워크·이동식 드라이브의 파일, 휴지통보다 큰 파일, 휴지통을 꺼 둔 드라이브. 이때 Windows 는 확인 없이 영구 삭제합니다. 보내기 전에 되는지 알아보고, 안 되면 그대로 두고 이유를 남깁니다.
  • USB 로 옮기다 뽑으면 둘 다 잃습니다드라이브를 넘는 이동은 복사한 뒤 원본을 지우는 일입니다. 복사본이 디스크에 실제로 닿은 것을 확인한 뒤에 원본을 지웁니다. 그만큼 느려지지만, 그게 맞습니다.
  • 폴더가 사실은 다른 곳일 수 있습니다정션·8.3 짧은 이름·관리 공유(\\host\C$)·장치 경로. 보호 폴더로 돌아 들어가는 네 가지 길을 각각 막습니다.
  • 이름을 고른 그 찰나에 뺏길 수 있습니다겹치지 않는 새 이름을 고른 직후, 다른 프로그램이 그 이름으로 파일을 만들 수 있습니다. 커널이 거절하도록 호출해서, 그 경우에도 남의 파일을 덮지 않습니다.
  • 맥에서 온 한글 파일은 이름이 다릅니다화면에는 계약서.pdf 로 똑같이 보이지만 저장된 형태가 달라, 규칙이 조용히 빗나갑니다. 비교할 때만 맞춰 봅니다 — 파일 이름 자체는 건드리지 않습니다.
  • 기록은 고칠 수 있으면 기록이 아닙니다정리할 때마다 앞 기록에 이어 봉인을 찍습니다. 한 줄을 고쳐도, 한 건을 지워도, 없던 걸 끼워 넣어도 그 뒤가 전부 어긋나 드러납니다.

CLI · 예약

작업 스케줄러에 물릴 수 있는 콘솔 실행 파일

GUI와 같은 DB·규칙을 그대로 씁니다. --apply 없이 실행하면 절대 파일을 옮기지 않습니다.

omnisort-cli.exe
# 대상 폴더 등록
omnisort-cli add "C:\Users\me\Downloads"

# 무엇이 어디로 갈지만 확인 (이동 없음)
omnisort-cli preview

# 규칙 추가: 계약서는 Contracts 로, 받는 중인 파일은 제외
omnisort-cli rules add --name 계약 --glob "계약*" --target Documents/Contracts
omnisort-cli rules add --name 임시 --glob "*.crdownload" --exclude

# 실제 정리 · 되돌리기 · 기록 확인
omnisort-cli run --apply --yes
omnisort-cli undo
omnisort-cli history

# 중복 파일 확인 · 원본만 남기고 휴지통으로
omnisort-cli duplicates
omnisort-cli duplicates --trash

# 큰 파일·오래된 파일·디스크 공간 보기 (읽기만)
omnisort-cli space --old-days 365

# 규칙 프리셋 목록 보기 · 학생용 묶음 넣기
omnisort-cli rules preset
omnisort-cli rules preset student

# 미리보기를 CSV 로 보관 (엑셀에서 열림)
omnisort-cli export plan.csv

# 매일 03:00 예약 — 작업 스케줄러 등록까지 한 줄로
omnisort-cli config schedule_time 03:00
omnisort-cli schedule --install
omnisort-cli schedule --check
비교

옮기는 것보다 어려운 건, 잘못 옮겼을 때입니다

폴더를 지켜보다 규칙대로 바로 옮기는 방식은 빠르지만, 무엇이 어디로 갔는지는 옮긴 뒤에 알게 됩니다. OmniSort 는 순서를 거꾸로 둡니다.

손으로 정리, 규칙대로 바로 옮기는 방식, OmniSort 비교
항목 손으로 정리 규칙대로 바로 옮기는 방식 OmniSort
옮기기 전에 목적지 보기 직접 판단 옮긴 뒤에 알게 됨 파일마다 목적지와 이유
잘못 옮겼을 때 기억에 의존 도구마다 다름 작업 단위로 전부, 예전 작업까지 되돌림
같은 이름의 파일 덮어쓰기 경고에 의존 도구마다 다름 어떤 경우에도 덮어쓰지 않음
확장자를 속인 파일 알아채기 어려움 내용은 확인하지 않음 내용을 읽어 ⚠ 표시
중복·큰 파일 치우기 탐색기에서 하나씩 따로 도구가 필요 한 프로그램 안에서, 휴지통으로만

내려받기

받아서 바로 실행합니다

설치 프로그램이 없습니다. 실행 파일 하나를 원하는 폴더에 두고 실행하면 끝입니다.

세 단계

  1. 릴리스 페이지에서 OmniSort.exe 를 받습니다 (명령줄로 쓰려면 omnisort-cli.exe 도)
  2. 받은 파일을 원하는 폴더에 두고 두 번 눌러 실행합니다

인터넷에 파일을 올리나요?

아니요. 스캔·분류·이동·기록이 전부 이 PC 안에서 끝나고, 파일 이름이나 경로가 밖으로 나가는 일은 없습니다. 설정과 로그는 %LOCALAPPDATA%\OmniSort\omnisort.db 한 파일에 들어갑니다.

인터넷을 전혀 쓰지 않나요?

기본은 한 번도 쓰지 않습니다. 관리자 화면에서 새 판 확인·공지·내려받기 수를 직접 켰을 때만 받아 오며, 그때도 파일 정보는 보내지 않습니다 (새 판 확인에는 판 번호만 담깁니다). 무엇이 나가는지는 그 화면에 주소까지 적혀 있습니다.

무료인가요?

네. 무료로 쓸 수 있고, 계정이나 결제가 필요 없습니다. 기본으로는 광고도 없습니다. 관리자 화면에서 공지 받기를 켰을 때 광고성 소식이 오면 ‘광고’ 라고 적어 보여 줍니다.

공간 찾기가 파일을 지우나요?

아니요. 공간 찾기는 읽기만 합니다. 목록에서 직접 고르고 확인한 파일만 휴지통으로 가고, 휴지통에서 되돌릴 수 있습니다. 네트워크 드라이브나 USB 메모리 같은 이동식 드라이브의 파일, 휴지통보다 큰 파일처럼 휴지통에 들어가지 못하는 것은 보내지 않고 알려 줍니다.

정리한 뒤 마음에 안 들면요?

[되돌리기]를 누르면 마지막 작업이 역순으로 복구됩니다. 작업 로그에서 예전 작업을 골라 되돌릴 수도 있습니다. 원래 자리에 같은 이름의 파일이 새로 생겼다면 덮어쓰지 않고 그 항목만 건너뛰며, 어떤 항목이 왜 건너뛰어졌는지 알려줍니다.

정리된 폴더를 또 정리하지는 않나요?

OmniSort가 만든 폴더에는 표시가 남아 다음 스캔에서 제외됩니다. 이미 제자리에 있는 파일도 후보에서 빠집니다.

파일이 잠겨 있거나 권한이 없으면요?

그 항목만 실패로 기록하고 나머지는 계속 진행합니다. 실패 사유는 작업 로그에서 볼 수 있고, 실패한 항목은 원래 자리에 그대로 있습니다.

설치가 필요한가요?

OmniSort.exe 하나만 받아 실행하면 됩니다. 관리자 권한도, 레지스트리 등록도 필요 없습니다. 지우고 싶으면 exe 와 위 DB 폴더를 삭제하세요. 예약 정리를 켰다면 먼저 omnisort-cli schedule --uninstall 로 작업 스케줄러 등록을 지웁니다.
