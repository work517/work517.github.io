개인정보 처리방침

시행일: 2026-10-12

Projectteamforyou(이하 ‘우리’)는 OmniSort(Windows 앱, Android 앱, 웹사이트 omnisort.win)를 만들고 운영합니다. 이 방침은 우리가 어떤 정보를 어떻게 다루는지를 있는 그대로 적습니다.

1. 한 줄 요약

우리는 여러분의 파일, 파일 이름, 폴더 경로를 가져가지 않습니다. 앱은 모든 처리를 여러분의 기기 안에서 합니다.

  • 회원가입과 로그인이 없고, 광고·분석용 외부 SDK 를 넣지 않았습니다. 맨 위의 얇은 띠(‘광고’ 표시)는 프로젝트팀포유의 다른 프로그램·앱·게임을 소개하는 링크일 뿐이며, 누를 때만 기기의 웹 브라우저가 열립니다.
  • Android 앱에는 인터넷 권한이 아예 없어서, 기술적으로 바깥과 통신할 수 없습니다.
  • 웹사이트는 방문과 내려받기 횟수를 날짜와 나라(두 글자)로만 셉니다. 누구인지 알 수 있는 정보는 남기지 않습니다.

2. 적용 범위

이 방침은 다음에 적용됩니다.

  • OmniSort for Windows
  • OmniSort for Android
  • 소개 웹사이트 omnisort.win
  • 내려받기 주소 dl.omnisort.win

3. 앱이 기기 안에서 다루는 정보 (Windows·Android 공통)

아래 정보는 정리 계획을 세우고, 파일을 옮기고, 되돌리기 위해서만 기기 안에서 쓰입니다. 우리에게 전송되지 않습니다.

  • 정리할 폴더 안 파일의 이름, 크기, 수정 시각, 확장자 — 어디로 옮길지 계산하는 데 씁니다.
  • 이미지 파일의 촬영 날짜(EXIF) — ‘날짜 폴더’ 옵션에서 촬영 날짜를 기준으로 고른 경우에만 읽습니다.
  • 파일 앞부분의 몇 바이트 — 확장자와 실제 내용이 다른 파일(예: 사진인 척하는 실행 파일)을 알려 드리기 위해 읽습니다. 내용을 저장하지 않습니다.
  • 작업 기록 — 옮긴 파일의 원래 위치, 새 위치, 이름. ‘되돌리기’를 위해 기기 안의 데이터베이스에 저장됩니다. 앱에서 지울 수 있고, 앱을 삭제하면 함께 사라집니다.
  • 설정 — 언어, 정리 옵션, 직접 만든 규칙.

Android 앱은 여러분이 시스템 폴더 선택기에서 직접 고른 폴더에만 접근합니다. ‘모든 파일 접근’ 권한을 허용하면 그 권한이 닿는 폴더에서도 같은 방식으로만 동작합니다.

4. 앱이 기기 밖으로 보내는 것

  • Android 앱: 없습니다. 앱에 인터넷 권한이 없습니다. (설정에서 ‘개인정보 처리방침’ 같은 링크나 맨 위의 소개 띠를 누르면 기기의 웹 브라우저가 열립니다. 그 뒤의 통신은 브라우저가 합니다.)
  • Windows 앱: 새 판 확인(기본으로 켜져 있고 설정에서 끌 수 있습니다)을 위해 하루 한 번 https 로 판 목록을 받아 옵니다(GET 한 번). 앱이 보내는 정보는 없고, 요청에 앱 이름과 판 번호가 담깁니다. 공지 받기와 내려받기 수 보기는 기본으로 꺼져 있으며, 켜면 같은 방식으로 공개 파일을 받아 옵니다. 맨 위의 소개 띠는 앱이 아무것도 받아 오지 않으며, 누르면 기본 웹 브라우저가 열립니다.

어느 경우에도 파일 이름, 경로, 개수는 밖으로 나가지 않습니다.

5. 웹사이트(omnisort.win)

  • 쿠키: 우리는 쿠키를 설정하지 않습니다. 가입과 로그인도 없습니다.
  • 누적 접속 수: 페이지를 열면 ‘날짜’와 ‘나라 코드(예: KR)’ 한 줄의 횟수만 올립니다. IP 주소, 브라우저 이름, 어디서 들어왔는지는 저장하지 않습니다. 한 줄이 여러 사람의 합이라 한 사람을 되짚어 찾을 수 없습니다.
  • 내려받기 수: ‘날짜·나라 코드·형태(한 파일/폴더형/명령줄)·판 번호’별 횟수만 셉니다. 같은 방식으로 개인을 식별하지 않습니다. 로봇과 미리 가져오기는 세지 않습니다.
  • Cloudflare Web Analytics: 어느 페이지가 얼마나 읽히는지 알기 위해 씁니다. 쿠키와 기기 식별용 지문을 쓰지 않으며, 유입 경로·브라우저 종류·나라 같은 방문 통계가 Cloudflare, Inc. 로 전달되어 처리됩니다.
  • 호스팅: 사이트는 GitHub Pages(GitHub, Inc.)에서 제공되고, 내려받기와 사이트 앞단은 Cloudflare 를 거칩니다. 이들은 서비스 운영과 보안을 위해 접속 기록(IP 주소 등)을 각자의 정책에 따라 처리할 수 있습니다. 우리는 그것을 개인을 식별하는 데 쓰지 않습니다.
  • 오프라인 저장: 사이트는 빠르게 열리도록 페이지 일부를 방문자의 브라우저에 저장(서비스 워커)합니다. 이 데이터는 방문자의 기기 안에만 있습니다.

6. 제3자 제공과 국외 이전

  • 우리는 개인정보를 판매하지 않으며, 광고나 마케팅 목적으로 제3자에게 제공하지 않습니다.
  • 웹사이트를 이용하면 위 5항의 사업자(미국 소재)의 서버에서 접속 정보가 처리될 수 있습니다. 앱을 쓰는 동안 파일에 관한 정보는 기기 밖으로 나가지 않습니다.

7. 보관과 삭제

  • 앱의 정보는 모두 기기에 있으며, 앱에서 작업 기록을 지우거나 앱을 삭제해서 직접 지울 수 있습니다. (Android: 설정 > 앱 > OmniSort > 저장공간 > 데이터 삭제)
  • 웹사이트의 합계 통계는 개인을 식별할 수 없는 집계 숫자이며, 서비스를 운영하기 위해 보관합니다.
