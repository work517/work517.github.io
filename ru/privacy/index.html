Политика конфиденциальности

Действует с: 2026-10-12

Projectteamforyou (далее — «мы») создаёт и поддерживает OmniSort (приложение для Windows, приложение для Android и сайт omnisort.win). В этой политике мы прямо и без умолчаний описываем, какие сведения мы обрабатываем и как.

1. Коротко

Мы не забираем ваши файлы, имена файлов и пути к папкам. Приложения выполняют всю обработку на вашем устройстве.

  • Нет регистрации и входа в аккаунт, и мы не встраивали сторонние SDK для рекламы или аналитики. Тонкая полоса вверху (с пометкой «Реклама») — это просто ссылка, представляющая другие программы, приложения и игры Projectteamforyou; веб-браузер на вашем устройстве открывается, только если нажать на неё.
  • У приложения для Android вообще нет разрешения на доступ в интернет, поэтому технически оно не может обмениваться данными с внешним миром.
  • Сайт считает посещения и скачивания только по дате и стране (два буквенных знака). Никаких сведений, позволяющих установить вашу личность, мы не храним.

2. На что распространяется политика

Эта политика распространяется на:

  • OmniSort для Windows
  • OmniSort для Android
  • Информационный сайт omnisort.win
  • Адрес для скачивания dl.omnisort.win

3. Какие сведения приложения обрабатывают на вашем устройстве (Windows и Android)

Сведения ниже используются только на вашем устройстве — чтобы составить план сортировки, переместить файлы и отменить перемещение. Нам они не передаются.

  • Имя, размер, время изменения и расширение файлов в папках, которые вы выбрали для сортировки, — по ним вычисляется, куда переместить каждый файл.
  • Дата съёмки изображения (EXIF) — считывается только если вы выбрали дату съёмки в качестве основы для папок по датам.
  • Первые несколько байтов файла — считываются, чтобы предупредить вас, если расширение файла не соответствует его реальному содержимому (например, исполняемый файл, выдающий себя за фотографию). Содержимое не сохраняется.
  • Журнал операций — прежнее местоположение, новое местоположение и имя каждого перемещённого файла. Он хранится в базе данных на вашем устройстве, чтобы вы могли отменить перемещение. Журнал можно очистить в приложении, а при удалении приложения он исчезает вместе с ним.
  • Настройки — язык, параметры сортировки и созданные вами правила.

Приложение для Android обращается только к тем папкам, которые вы сами выбрали в системном средстве выбора папок. Если вы предоставите разрешение «Доступ ко всем файлам», приложение продолжит работать так же и только в тех папках, до которых это разрешение дотягивается.

4. Что приложения отправляют за пределы устройства

  • Приложение для Android: ничего. У приложения нет разрешения на доступ в интернет. (Если в настройках нажать на ссылку, например «Политика конфиденциальности», или на полосу вверху, откроется веб-браузер вашего устройства; дальнейший обмен данными выполняет уже браузер.)
  • Приложение для Windows: для проверки новых версий (включена по умолчанию, отключается в настройках) раз в день по https загружается список версий (один запрос GET). Приложение не отправляет никаких сведений; в запросе указываются название приложения и номер версии. Получение объявлений и просмотр числа скачиваний по умолчанию отключены; если вы их включите, они таким же образом загружают общедоступные файлы. Полоса вверху ничего не загружает; при нажатии на неё открывается веб-браузер по умолчанию.

Ни в одном случае имена файлов, пути и их количество за пределы устройства не передаются.

5. Сайт (omnisort.win)

  • Файлы cookie: мы не устанавливаем cookie. Регистрации и входа в аккаунт тоже нет.
  • Общее число посещений: при открытии страницы увеличивается только счётчик одной строки — «дата» и «код страны» (например, KR). IP-адрес, название браузера и источник перехода не сохраняются. Строка — это сумма по многим людям, поэтому по ней нельзя выследить отдельного человека.
  • Число скачиваний: мы считаем только по дате, коду страны, виду (один файл / вариант в папке / командная строка) и номеру версии. Так же, как и выше, это не позволяет идентифицировать людей. Роботы и предварительная загрузка не учитываются.
  • Cloudflare Web Analytics: используется, чтобы понимать, какие страницы и как часто читают. Он не использует cookie и цифровой отпечаток устройства; статистика посещений — источник перехода, тип браузера, страна — передаётся компании Cloudflare, Inc. и обрабатывается ею.
  • Хостинг: сайт размещён на GitHub Pages (GitHub, Inc.), а скачивание и внешний уровень сайта проходят через Cloudflare. Эти компании могут обрабатывать журналы доступа (в том числе IP-адреса) в соответствии со своими политиками — для работы сервиса и обеспечения безопасности. Мы не используем эти сведения для идентификации кого-либо.
  • Автономное хранение: чтобы сайт открывался быстро, часть страниц сохраняется в браузере посетителя (service worker). Эти данные остаются только на устройстве посетителя.

6. Передача третьим лицам и трансграничная передача

  • Мы не продаём персональные данные и не передаём их третьим лицам в рекламных или маркетинговых целях.
  • При использовании сайта сведения о доступе могут обрабатываться на серверах поставщиков услуг, указанных в разделе 5 (они находятся в США). Пока вы пользуетесь приложениями, сведения о ваших файлах за пределы устройства не передаются.

7. Хранение и удаление

  • Все сведения приложений находятся на вашем устройстве, и вы можете удалить их сами — очистив журнал операций в приложении или удалив приложение. (Android: Настройки > Приложения > OmniSort > Хранилище > Очистить данные)
  • Суммарная статистика сайта — это агрегированные числа, по которым нельзя никого идентифицировать; мы храним её для работы сервиса.
